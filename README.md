# SATCP: Secant–Approximate-Tangent Curvature Predictor

This repository contains the source code associated with the manuscript:

> Fan Liu and Qinglin Duan, *A secant–approximate-tangent curvature predictor for arc-length tracing of geometrically nonlinear postbuckling paths*, prepared for **Engineering Structures**.

The released code provides:

- the MATLAB implementation of the proposed secant–approximate-tangent curvature predictor (SATCP);
- a legacy FEniCS/DOLFIN implementation of the SATCP arc-length solver;
- the two shell benchmarks reported in Sections 4.6 and 4.7 of the manuscript.

The finite element formulations used by the benchmarks are not claimed as original contributions. The contribution of this repository is the SATCP continuation solver and its integration into the corresponding finite element frameworks.

## Legacy FEniCS implementation

### Requirements

The Python scripts use the legacy `dolfin` interface and are **not** written for FEniCSx.

Required software includes:

- legacy FEniCS/DOLFIN 2019.x;
- Python 3;
- UFL;
- NumPy;
- Matplotlib for the optional figures generated by `Example7.py`;
- a DOLFIN installation with access to the selected linear solver, such as MUMPS.

Place the following files in the same directory:

```text
Example6.py
Example7.py
Present_solver.py
```

Run the pinched semi-cylindrical shell benchmark using:

```bash
python3 Example6.py
```

Run the hinged cylindrical panel benchmark using:

```bash
python3 Example7.py
```

The run options near the beginning of each benchmark script control whether numerical data, displacement fields and figures are written to disk.

### Recovering the approximate-tangent predictor

The approximate-tangent predictor (ATP) is recovered by suppressing the curvature-induced rotation. Set:

```python
phi_max=0.0
```

when constructing `force_control`. With this setting, the predictor direction reduces to the approximate tangent while the corrector, convergence criterion, adaptive arc-length rule and restart procedure remain unchanged.

## MATLAB implementation

`main_arclength_Present.m` is not a standalone finite element program. It is designed to be used with:

> Chennakesava Kadapa, `ArcLengthMethod`  
> https://github.com/chennachaos/ArcLengthMethod

### Usage

1. Clone or download the upstream `ArcLengthMethod` repository. This release has been compatibility-tested with commit `b250d639ce7bd497d568eb262b8df6cb723e273c`.
2. Copy `main_arclength_Present.m` into the upstream working directory and replace the upstream `solve_arclength_split.m` with the version released here.
3. Select the required unmodified upstream benchmark input file near the beginning of `main_arclength_Present.m`.
4. Run:

```matlab
main_arclength_Present
```

The upstream repository supplies the finite element assembly routines, element formulations and benchmark input files. This repository supplies the SATCP-specific MATLAB main program and its MATLAB-compatible split corrector. The released corrector returns the unit reference-load response `du1`, which is required to construct the SATCP approximate tangent.

To recover ATP in the MATLAB implementation, set:

```matlab
phiMax = 0.0;
```

## Reproducibility scope

The repository releases the proposed SATCP implementation and the two shell benchmark drivers. It does not redistribute the complete source code of the upstream `ArcLengthMethod` project.

The comparison predictors reported in the manuscript are not necessarily included in this release. Numerical comparisons should therefore use identical finite element models, correctors, convergence tolerances, step-control rules and restart procedures, with only the predictor construction changed.

CPU times depend on the operating system, compiler, linear algebra backend and hardware. Timing results should therefore be interpreted comparatively within the same environment.
